# Preview policy

`page-01.png` is a direct 200-dpi `pdftoppm` render of the compiled A4 CV. The build refreshes the public GitHub avatar before compilation. The preview's intrinsic size is approximately 1654 × 2339 px. It must not be cropped, resized, composited, sharpened, annotated, or redrawn, and README files must not set HTML width/height overrides.
