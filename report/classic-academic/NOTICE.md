# Notice

This template does not commit font binaries. Its deterministic font contract follows `cigit-zgy/water-modeling-notes`: Latin Modern Sans, Maple Mono, LXGW WenKai Screen, and Latin Modern Math.

Maple Mono and LXGW WenKai Screen are downloaded to a local gitignored cache by `scripts/setup-fonts.sh`; there is no font fallback path. Their upstream licenses remain applicable.

The layout is an independent implementation inspired by the typographic principles of the ClassicThesis family.
