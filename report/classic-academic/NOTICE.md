# Notice

This template does not commit font binaries. Its deterministic font contract follows `cigit-zgy/water-modeling-notes`: Latin Modern Sans, Maple Mono, LXGW WenKai Screen, and Latin Modern Math.

Latin Modern Sans is downloaded from the exact WOFF2 assets in `water-modeling-notes` pinned to commit `462c5e1609978b27fc0774780229fc41a0aba8f8`; Maple Mono is pinned to Fontsource 5.3.0; LXGW WenKai Screen is pinned to 1.522. These assets are prepared in the local gitignored `fonts/` cache by `scripts/setup-fonts.sh`. There is no font fallback path.

The relevant upstream font licenses remain applicable. The layout is an independent implementation inspired by the typographic principles of the ClassicThesis family.
