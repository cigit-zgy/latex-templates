# Notice

This template does not commit font binaries. Its project-wide deterministic font contract is XCharter for Latin serif text, XCharter-Math for mathematics, Latin Modern Sans for structural sans-serif text, Maple Mono 5.3.0 for code, and LXGW WenKai Screen 1.522 for Chinese.

XCharter, XCharter-Math, and Latin Modern Sans are supplied by the TeX distribution. Maple Mono and LXGW WenKai Screen are prepared in the local gitignored `fonts/` cache by `scripts/setup-fonts.sh`. There is no font fallback path.

The relevant upstream font licenses remain applicable. The layout is an independent implementation inspired by the typographic principles of the ClassicThesis family.
