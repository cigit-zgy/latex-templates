\Localized{This report template is designed for scientific and technical documents that require the same restrained visual language as the companion thesis template without adopting a book structure. The report uses a section-based hierarchy, a single-sided page model, a compact running header, mandatory full-width tables, scientific mathematics, code listings, and bibliography support.}{本报告模板面向科学与技术文档，在保持与学位论文模板一致的克制视觉语言的同时，不采用书籍结构。报告使用基于节的层级、单面页面模型、紧凑页眉、强制满行宽表格、科学公式、代码列表与参考文献支持。}
