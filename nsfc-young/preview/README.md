# Preview

`application.png` and `content.png` are direct 100-DPI renders of pages 1 and 2 of the pinned upstream compiled `main-YF.pdf` at commit `11a02726f6190fcb89859dfaed18e3d1d68af0b8`.

The reference PDF is used because the exact SimSun, KaiTi, FangSong, and Arial font environment is not available in public CI. The preview workflow does not rebuild the NSFC template with substitute fonts.
