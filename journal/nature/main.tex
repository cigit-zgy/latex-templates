\section{Content-page specimen}
This second page is deliberate preview content. It validates the body typography, heading hierarchy, mathematical typesetting, paragraph spacing, and reference handling of the current repository template. It does not override any dimensions, fonts, spacing rules, or other settings owned by \texttt{sn-jnl.cls}.

A reusable manuscript template should remain predictable when ordinary prose spans multiple paragraphs. For that reason, this page contains representative scientific text rather than blank vertical space. Model descriptions often combine definitions, assumptions, observations, and quantitative comparisons. These elements should retain the publisher defaults without local formatting patches.

\subsection{Representative analysis}
Suppose that an observable $x$ changes according to a simple balance,
\begin{equation}
  \frac{\mathrm{d}x}{\mathrm{d}t}=r_{\mathrm{in}}-r_{\mathrm{out}}.
\end{equation}
The expression is included only to verify equation placement and surrounding text. The sample remains intentionally domain-neutral so that the directory can be reused as a clean starting point for different scientific manuscripts.

\subsection{Reproducible preview contract}
The committed preview is generated from this source file, not from a precompiled external PDF. The CI workflow requires at least two pages and renders the first two pages at 150 DPI. The two PNG files must have identical pixel dimensions before they can be committed.
