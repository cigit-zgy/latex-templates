\section{\Localized{Research Background}{研究背景}}
\label{sec:introduction:background}

\Localized{Mechanistic models encode domain knowledge through explicit mathematical structures, whereas data-driven models learn relationships from observations. Hybrid approaches combine these sources of information and are increasingly used for scientific modelling \autocite{rackauckasUniversalDifferentialEquations2020}.}{机理模型通过显式数学结构表达领域知识，数据驱动模型则从观测数据中学习关系。混合建模将两类信息结合，并逐渐应用于科学建模 \autocite{rackauckasUniversalDifferentialEquations2020}。}

\subsection{\Localized{A Generic Dynamical System}{通用动力系统}}

\Localized{A compact representation of a process-based model is}{过程模型可以简洁表示为}

\begin{equation}
  \frac{\mathrm{d}\symbf{x}}{\mathrm{d}t}
  = \symbf{S}\,\symbf{r}(\symbf{x},\symbf{\theta}),
  \label{eq:introduction:dynamics}
\end{equation}

\Localized{where \(\symbf{x}\) denotes the model state, \(\symbf{S}\) the stoichiometric structure, \(\symbf{r}\) the process-rate vector, and \(\symbf{\theta}\) the parameter vector. Equation~\ref{eq:introduction:dynamics} is used here only to demonstrate the mathematical typography.}{其中，\(\symbf{x}\) 表示模型状态，\(\symbf{S}\) 表示化学计量结构，\(\symbf{r}\) 表示过程速率向量，\(\symbf{\theta}\) 表示参数向量。式~\ref{eq:introduction:dynamics} 仅用于展示数学公式排版。}

\section{\Localized{Template Design Principle}{模板设计原则}}

\Localized{Project-specific information is restricted to the metadata and theme configuration layer. Typography, page geometry, chapter formatting, running heads, captions, and code listings remain in the template style layer. This separation prevents scientific chapter files from accumulating local formatting commands.}{项目特定信息仅放在元数据与主题配置层。字体、页面几何、章节格式、页眉、题注和代码样式统一保留在模板样式层，从而避免科学正文文件积累局部格式命令。}
