# Local font cache

This directory is populated by `../scripts/setup-fonts.sh`. Font binaries are intentionally not committed.

The template uses an exact, no-fallback contract:

- Latin Modern Sans (TeX Live / MacTeX OpenType family)
- Maple Mono, Fontsource package version 5.3.0
- LXGW WenKai Screen, version 1.522
- Latin Modern Math (TeX Live / MacTeX)

Run the setup script before the first build.
