# Attribution and design note

This template is an independent XeLaTeX implementation inspired by the typographic architecture of **ClassicThesis**, originally created by André Miede, and by the reference dissertation used to calibrate this repository's layout.

No font files are distributed and no ClassicThesis source files are vendored here. The page architecture is recreated with standard LaTeX packages (`book`, `titlesec`, `fancyhdr`, `geometry`, `fontspec`, and related packages) so that the template can be maintained independently.

The accent and hyperlink colours are project-specific choices rather than part of ClassicThesis.
